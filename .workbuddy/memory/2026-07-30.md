## 部署阻塞（vocabcards → GitHub → Cloudflare）
- GitHub 网页在用户网络下超时（ERR_CONNECTION_TIMED_OUT），网页端无法上传。
- 命令行直推被沙箱代理挡掉；用户本机终端直推 `git push -f origin main` 报 `Missing DESKTOP_PORT`（凭据助手需经 GitHub Desktop 的「Repository → Open in Terminal」启动的终端才带该环境变量）。
- 可行方案（已告知用户）：① GitHub Desktop 内 **Branch → Force Push**；或 ② Desktop 菜单 **Repository → Open in Terminal** 后在该终端跑 `git push -f origin main`。本地 remote=https，凭据由 Desktop 提供，-f 覆盖远程旧的 “Add files via upload” 历史（与本地无关历史，安全）。
